# University Admission System

## Project Overview
University Admission System is a web-based application developed using Java, JSP, HTML, CSS, and MySQL. The system automates the university admission process by allowing students to register, apply for admission, check application status, and view results. Administrators can manage universities, courses, applications, schedules, and student records.

## Features
- Student Registration and Login
- University and Course Management
- Admission Application
- Application Status Tracking
- Hall Ticket Generation
- Exam Schedule Management
- Marks Management
- Student and Admin Dashboards
- Password Recovery

## Software Architecture
This project follows the **Client–Server Architecture**.

### Client
- Web Browser
- HTML
- CSS
- JSP Pages

### Server
- Apache Tomcat
- Java
- JSP
- JDBC

### Database
- MySQL Database

## Client–Server Workflow

1. User accesses the application through a web browser.
2. The browser sends an HTTP request to the Tomcat server.
3. JSP and Java process the request.
4. JDBC connects the application to the MySQL database.
5. The database returns the requested data.
6. The server sends the response back to the browser.
